# Independent implementation policy

TimeFlow Studio is an independent implementation of common image-sequence,
timelapse, metadata, and compositing workflows.

Contributions may rely on:

- Public documentation and standards.
- File formats created by the contributor or supplied with permission.
- User-visible behavior observed through normal product use.
- Original algorithms, UI designs, tests, and artwork.

Contributions must not contain or derive from:

- Decompiled or copied proprietary source code.
- Extracted icons, images, text catalogs, layouts, or other protected assets.
- Private keys, certificates, credentials, activation data, or customer data.
- Instructions or code intended to defeat another product's access controls,
  licensing, signatures, or certificate validation.

When compatibility work is proposed, document the public input/output behavior
being implemented and provide an independently written test. Maintainers may
reject a contribution when its provenance is unclear.
