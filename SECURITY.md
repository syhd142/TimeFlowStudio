# Security policy

## Supported version

Until the first stable release, security fixes are provided only for the newest
Beta release and the current default branch.

## Reporting a vulnerability

Please use the repository's **Security** tab to open a private vulnerability
report. Do not publish exploit details, private media, XMP metadata, or local
file paths in a public issue.

Include the affected version, macOS version, reproduction steps, impact, and a
minimal sample that you are allowed to share. A maintainer will acknowledge a
complete report when it is reviewed; no fixed response-time guarantee is made
for this volunteer project.

Ordinary crashes, export-quality problems, and feature requests can use the
public issue templates.
