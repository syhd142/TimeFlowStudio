# Support

Use GitHub Issues for reproducible bugs and feature requests. Before reporting
an export problem, retry a short sequence and note:

- TimeFlow Studio version and macOS version.
- Mac model and available memory.
- Source image format, frame count, dimensions, and selected range.
- Export preset, codec, color space, scaling mode, and star-trail options.
- Whether the output plays correctly in QuickTime Player and VLC.

Do not upload private photographs or metadata unless you are comfortable making
them public. Security issues belong in a private security report; see
[SECURITY.md](SECURITY.md).

Beta releases are provided without guaranteed response times or professional
support.
