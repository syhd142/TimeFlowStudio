# Privacy

TimeFlow Studio processes image sequences locally on the Mac.

- The current application does not require an account.
- It does not include analytics, advertising, telemetry, or an update checker.
- It does not upload photos, metadata, projects, or export settings.
- Projects and recovery data are stored locally. XMP export writes beside the
  source images and keeps replaced sidecars in a local backup folder.

macOS and software used to download or distribute the application may have
their own privacy behavior. If network features are added later, this document
must be updated before release.
